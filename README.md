# 천체의 위치와 좌표계 — 수업 시연용 웹앱

고등학교 지구과학Ⅱ 'III. 우주 > 01. 천체의 위치와 좌표계' 단원의 교사 시연용 인터랙티브 웹앱입니다.
프로젝터로 띄워 놓고 조작하며 개념을 설명하는 수업 도구로, 교과서 그림 III-3~III-7의 시점·색 역할·용어를 따랐습니다.

## 사용법

`celestial-coordinates.html` 파일 하나가 전부입니다. 내려받아 브라우저에서 열면 **오프라인에서 바로 동작**합니다.
(외부 CDN·서버 불필요, 설치 없음)
